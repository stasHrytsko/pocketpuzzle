# Perfect Fit

Карточка игры. Источник: `stazzi/apps/casual/perfect-fit/` (SPEC.md, README), прочитано 2026-11-03 по просьбе автора. Внутри stazzi идея называется **Build & Pack** (slug `build-pack`), в игре — Perfect Fit. Статус в stazzi — playable.

- **Статус:** MVP, ядро. **Уровней:** 50 (каталог 6, 2026-10-27).
- **Питч:** выбери число, собери из стольких клеток свою фигуру и уложи её на поле. Числа известны заранее и в сумме ровно заполняют поле.

## Правила
- В лотке ряд чисел уровня. Тап по числу N выбирает его.
- В конструкторе 4×4 тапом (или проведением пальцем) отмечаешь ровно N клеток, связных по сторонам. Без поворота и отражения.
- Готовую фигуру перетаскиваешь на пустые клетки поля; число гаснет, конструктор очищается.
- **Победа:** использованы все числа и поле заполнено без пустых клеток.
- **Поражение:** ни одно оставшееся число никуда не помещается. Есть один Undo на попытку и «Заново»; игра не подсказывает, что уровень уже нерешаем.
- Четыре семейства правил, каждое в двух вариантах (полный конструктор 4×4 и «фигурный»): обычные, числа, парные точки, швы; последние два уровня смешанные.

## Что на экране
Поле сверху (подстраивается под экран), внизу лоток: конструктор 4×4, числа, «Очистить», счётчик `k/N`. Фигуры — цветные плитки (размеры отличаются цветом).

## Уровни и сложность
Фигуры 2–7 клеток, до 9 фигур на уровне, поле до 8×8. Уровни сгенерированы (`tools/make-campaign.ts`, seed 6270): генератор берёт из 12–30 кандидатов тот, где «жадный» игрок чаще попадает в ловушку; решение каждого известно по построению. Это отбор по солверу, не плейтест. Сложность растёт внутри каждой половины каталога, затем снова падает при смене правила — **для волны в письме одного номера уровня мало, нужна отдельная оценка** [проверить, есть ли она в `campaign-report.json`].
