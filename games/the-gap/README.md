# The Gap

Карточка игры. Источник: `stazzi/apps/casual/the-gap/` (SPEC.md, README, IDEA.md), прочитано 2026-11-03 по просьбе автора. Статус в stazzi — playable.

- **Статус:** MVP, ядро. **Уровней:** 8 (`the-gap-levels.json`).
- **Питч:** скользи цветными квадратами к выходам, каждый ведёт в свою колбу. Колбы стартуют перемешанными, поэтому квадраты приходится доставать обратно, а это возможно, только пока свободна клетка у выхода.

## Правила
- Поле-сетка со стенами и четырьмя пронумерованными выходами в рамке. Колбы (ёмкость 2–4) уже наполнены и перемешаны.
- Свайп по квадрату двигает его до упора (стена, другой квадрат, край). Если доехал до клетки выхода и движется к щели, уходит в колбу выхода (если есть место) и ложится сверху.
- Тап по колбе достаёт верхний квадрат на клетку выхода, если она свободна. Достаётся только верхний.
- Ход, который ничего не меняет, не засчитывается.
- **Победа:** поле пусто, каждый цвет лежит ровно в одной колбе, каждая непустая колба одноцветная.
- **Проиграть нельзя** (решение автора stazzi, 2026-10-11): ходов сколько угодно, поражения и звёзд нет, считаются только ходы против «Best possible».
- Цвет квадрата дублируется значком (круг, треугольник, ромб).

## Что на экране
Название уровня, пилюля «Moves k» (без лимита), цели по цветам, поле с выходами 1–4, четыре колбы, «?» (пять шагов с картинками), «Заново».

## Уровни и сложность
8 уровней, первый — разминка в два хода; каждый с сохранённым оптимальным решением (`opt`). Уровни авторские/из солвера, сложность растёт по номеру. **Восемь уровней при ежедневном письме кончатся быстро** — открытый вопрос продукта (`CONCEPT.md` §11).
