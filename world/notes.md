# Записки и главы

## Что для всех, что разное **[решение]**
- **Главы основной линии** — одинаковые у всех, идут по письмам (с MVP).
- **Записки** — разные у разных игроков; позже пересылаются через почтальона (v2).
- Картину мира целиком никто не видит один — её собирают вместе (вики).

## Как раздавать разное без сервера **[предложение]**
У каждой установки своё **зерно**. Из него детерминированно выбирается, какие записки из пула и какие куски шифров придут этому игроку. Работает локально, как всё в MVP. С соцслоем зерно можно привязать к анонимному ID.

## Формат записки **[предложение]**

```
ID:        N-0001
Тип:       обрывок письма | пометка на полях | опись | запись почтальона | чужой почерк | скан места   (WORLD.md §6)
Слой:      1 / 2 / 3 / ∞
Для кого:  все | пул A / B / C… (по зерну)
Факт:      P-06 (какие факты канона использует)
Вопрос:    какой новый вопрос оставляет
Шифр:      C-0x или —
Текст:     ≈ 30 секунд чтения
```

## Правила текста
- Один факт + один новый вопрос.
- Понятна сама по себе; полный смысл — рядом с другими.
- Читается в духе текущего слоя: не врёт и не раскрывает раньше времени (`WORLD.md` §0.1).
- Почтальон не диагностирует игрока; зеркало без указки.
- В каждой — маленькая законченная радость: образ, деталь, странная фраза. Большинство игроков не дойдёт до третьего слоя, первый должен радовать сам по себе.

## Запас
Мир без конца **[решение]** → нужен процесс, а не разовый текст: пул записок вперёд на [N] недель, пополнение по графику автора.
