# Pocket Puzzle — структура игры

**Версия 0.1 · 2 ноября 2026.** Иерархия экранов и переходы, без графики. Решение автора (2026-11-03): старый дизайн удалён, новый — референсы в `design/ref/`; сначала структура, потом арт. Подробные состояния каждого экрана — `design/SCREENS.md` (ID в скобках отсюда ведут туда).

## 1. Дерево

```
Запуск (SYS-01, SYS-02)
└── ГЛАВНАЯ (HOME) — три раздела, открывается на «Сегодня»
    │   шапка: ⚙ настройки · низ: Letters · Today · Games + одна главная кнопка
    │
    ├── Letters — ИСТОРИЯ ПИСЕМ (MAIL-00)
    │   ├── Calendar — история писем (MAIL-05, MAIL-01)
    │   │   └── прошлое письмо, только чтение (LET-04)
    │   └── Notes — записки почтальона (LORE-01)
    │       └── записка (LORE-02)
    │
    ├── Today — ЗАДАНИЕ ДНЯ
    │   └── письмо дня (LET-01)
    │       ├── вступление — только в первом письме (LET-02)
    │       ├── задачи 1…N → уровень игры (PUZ-01)
    │       │   └── решено + марка (PUZ-06) → следующая задача / к письму
    │       ├── записка — запечатана, пока не решено всё (LET-05)
    │       └── всё решено → конверт: марки + отправка (ENV-01)
    │           └── отправлено, штемпель (ENV-04) → записка (LORE-02) → главная
    │
    ├── Games — ВСЕ ИГРЫ (COL-01)
    │   ├── пришедшая игра → страница игры: уровни (COL-04)
    │   │   └── уровень (PUZ-01) → решено, без марки (PUZ-08) → следующий уровень
    │   └── не пришедшая игра → «придёт по почте» (COL-02)
    │
    └── ⚙ Настройки (SET-01): звук, вибрация, напоминание, экспорт, сброс, о приложении
```

Уровней вложенности три: **главная → экран → уровень игры**. Глубже не уходим. Как главная выглядит (вкладки, комната или другое) — **[открыто]**, решаем после структуры, вместе с артом.

## 2. Три раздела

| Раздел | Что внутри | Зачем |
|---|---|---|
| **Today — задание дня** | Письмо дня: N задач (уровни разных игр), записка почтальона, отправка | Ежедневный ритуал, ядро продукта |
| **Games — все игры** | Пришедшие игры, у каждой уровни по порядку; не пришедшие — «придёт по почте» | Играть сколько хочешь, вне расписания |
| **Letters — история писем** | Календарь отправленных писем, записки почтальона | Накопленный результат вместо стрика; мир по кусочкам |

Задача из письма — это **следующий непройденный уровень игры**, и он засчитывается в прогресс этой игры **[решение]**. То есть «Задание дня» и «Все игры» ведут в одни и те же уровни, разный только вход и награда (марка есть только в письме).

## 3. Главная

- Три раздела: **Letters ← Today → Games**; открывается на Today **[решение]**. Переход — свайп или тап по подписи внизу.
- **Главная должна показывать состояние дня, не только содержимое [решение автора: «комната показывает состояние»; форму пересматриваем]:** письмо пришло / в работе / отправлено; в календаре закрашены дни с письмом; растёт стопка записок; на следующем месте среди игр — «придёт по почте».
- Письмо дня открывается по карточке письма или по главной кнопке.

### Главная кнопка — одна на все разделы

Текст зависит от того, где игрок в цикле дня **[решение]**:

| Состояние дня | Кнопка | Куда ведёт |
|---|---|---|
| Письмо пришло, не открыто | **New letter** | Письмо дня |
| Задачи в работе | **Continue letter · task 2 of 3** | Следующая нерешённая задача |
| Все задачи решены | **Decorate envelope** | Конверт |
| Письмо отправлено, записка не прочитана | **Read the note** | Записка |
| Всё сделано на сегодня | **Continue · Arrow Flip, level 13** | Последняя игра, которую игрок открывал |

## 4. Цикл дня

```
пришло письмо → открыл → решаю задачи (марка за каждую) → всё решено
→ клею марки на конверт → отправил → читаю записку → свободная игра до завтра
→ завтра новое письмо
```

- Письмо не запирается ничем: доступно с первого запуска, без уровней и рекламы **[решение]**.
- Пропустил день — письмо ждёт, календарь не краснеет **[решение]**. Неотправленное вчерашнее можно закончить (HOME-05).
- Записка не стоит на пути: решил всё → сначала конверт, записка — после отправки **[решение]**.
- **В письме 3 задачи волной, как в NYT Pips: лёгкая → средняя → трудная [решение, 2026-11-02].** По одной из трёх разных игр: берётся следующий непройденный уровень каждой, письмо ставит их по возрастанию сложности. Трудная — та самая победа. Первое письмо: по одной задаче из каждой из трёх игр (ONB-02).
- Когда игр больше трёх, игры в письме чередуются **[предложение]**.

---

## 5. Навигация — правила

- **Назад** всегда возвращает на один уровень вверх.
- Из уровня игры выход ведёт туда, откуда пришёл: в письмо или на страницу игры.
- Подписи Letters · Today · Games и главная кнопка видны только на главной; в письме, игре и конверте их нет.
- Главная не сбрасывает положение (раздел, прокрутка) при возврате.
- Прогресс сохраняется на каждом шаге; закрыл приложение посреди уровня — откроется там же (SYS-04).

---

## 6. Первый запуск

1. Заставка → главная, раздел Today, письмо уже пришло **[решение: отдельного приветствия нет]**.
2. Главная кнопка: **New letter**.
3. Первое письмо: вступление (мир и как играть) + задачи из трёх игр ядра; эти три игры появляются в разделе Games.
4. Первая задача каждой игры — с обучением прямо на поле (ONB-03).
5. Первая марка, первый конверт, первая отправка — с одной подсказкой каждая (ONB-04, ONB-05).
6. После первой отправки — «Напомнить про письмо?» и системный запрос уведомлений (ONB-06, ONB-08).
