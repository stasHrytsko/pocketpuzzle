# Кликабельный прототип Pocket Puzzle

**Смотреть:** https://claude.ai/artifact/E7n5buGvbbQbmWLGxdGHr2 (приватный; открыть может владелец аккаунта и те, с кем он поделился через меню Share).

Здесь — копия исходников для истории и восстановления. Это файлы дизайн-холста claude.ai (формат `.dc.html`), в обычном браузере напрямую не открываются.

| Файл | Что это |
|---|---|
| `Main.dc.html` | Весь кликабельный прототип: экраны, состояния, логика переходов |
| `Envelope.dc.html` | Компонент конверта (слоты марок, штемпель) |
| `Stamp.dc.html` | Компонент марки |
| `canvas.json` | Раскладка холста и запуск прототипа |

Поля игр — заглушки, тексты глав — плейсхолдеры. Карта экранов — `design/SCREENS.md`, значения — `design/pocket-puzzle-tokens.json`.

При изменении прототипа на claude.ai обновлять копию здесь.
