# Игры

Папка под каждую игру Pocket Puzzle (решение автора, 2026-11-02). Сейчас здесь только документы; код игр будет в `unity/Assets/PocketPuzzle/Games/<Game>/` (`TECH-UNITY.md` §5), уровни — в `unity/Assets/StreamingAssets/levels/`.

| Папка | Игра | В MVP | Уровней сейчас |
|---|---|---|---|
| `arrow-flip/` | Arrow Flip | да | 25 (`TECH-UNITY.md` §3) |
| `perfect-fit/` | Perfect Fit | да | 50 + 6 + 1 (`TECH-UNITY.md` §3) |
| `the-gap/` | The Gap | да | 8 (`TECH-UNITY.md` §3) |

Новая игра — новая папка с тем же набором файлов.

## Что лежит в папке игры

- `README.md` — карточка игры: правила, что на экране, состояния, уровни и как считается их сложность, открытые вопросы.
- `levels/` — уровни в общем формате (когда будут): номер, данные поля, **оценка сложности** — нужна для волны в письме (лёгкая → средняя → трудная).
- `art/` — арт этой игры (когда будет).
- `design/` — макеты и скриншоты экранов игры.

## Что общее для всех игр (не дублировать в папках)

Оболочка запускает любую игру одинаково: дай уровень N → игрок играет → «решено» и время решения (для марки) → сохранить или восстановить попытку. Шапка игры (назад, Level N, правила, заново), экран «решено», марка, страница уровней — общие, описаны в `design/STRUCTURE.md` и `design/SCREENS.md` §5.
