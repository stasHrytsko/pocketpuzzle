# Pocket Puzzle — полная карта экранов

**Дата:** 31 октября 2026. Источник решений — `CONCEPT.md`; значения — `design/pocket-puzzle-tokens.json`.
Обозначения: **MVP** — нужно к первому релизу; **Позже** — после MVP; **Соц** — социальный слой (этап 2+).

## Три раздела

Связка Today / Calendar / Collection из раннего разбора Almanac в нашей схеме выглядит так:

| Раздел из разбора | У нас | Зачем |
|---|---|---|
| Today | **Главная** — сегодняшнее письмо | Ежедневная привычка |
| Calendar | **Моя почта** — архив писем, показанный календарём по дням | Накопленный результат без стрика: каждый день — конверт; пропуск нейтральный |
| Collection | **Коллекция** — игры, пришедшие по почте | Играть сколько хочешь, вне расписания |

Отличие от разбора: коллекция открывается письмами (`CONCEPT.md` §4), а не сразу целиком. Ежедневное письмо не заперто ничем.

## Сознательно не делаем

Карта прогрессии (Journey), запертые ежедневные задачи, экраны стрика и его «спасения», рейтинги и процентили, профиль и друзья, магазин, валюта, пейволл, реклама и рекламные разблокировки, запрос «оцените приложение» посреди ритуала. Причины — `CONCEPT.md` §6 и приложения А–Б.

## Что есть у Almanac, а у нас нет — и почему

| Almanac | Мы |
|---|---|
| Journey с открытием Daily после уровня 5 | Нет: письмо доступно с первого запуска |
| Rewarded-реклама за доступ к задачам | Нет рекламы в MVP |
| Zen / Infinite, пейволл | Нет монетизации в MVP |
| Профиль, друзья, сравнение времени | Нет; соцслой — через почтальона, анонимно |
| Daily streak с календарной полосой | Календарь писем без стрика, счётчик отправленных |
| Settings: звук, язык, тема, сброс данных | Есть все, тема — позже |
