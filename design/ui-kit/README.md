# UI kit Pocket Puzzle

Новый UI kit приложения (решение автора, 2026-11-02). `@stazzi/puzzle-ui` не используем и с ним не сверяем.

Файлы и папки:
- `DESIGNER-TASK.md` — короткое задание дизайнеру для отправки вместе с вложениями.
- `UI-KIT-BRIEF.md` — **бриф дизайнеру v0.1** (один дизайнер на всё: UI kit, почта, три игры, комната, иконки; решение автора, 2026-11-02).
- `refs/` — референсы кита: четыре варианта настроения (`kit-variant-*.jpg`, основа — вариант 2) и как игры выглядят сейчас (`current-*.png`, из `stazzi`).
- `main-page/` — главная «Комната» (ТЗ иллюстратору, поведение, референсы).

Сюда автор складывает материалы для UI kit: макеты, компоненты, иконки, шрифты, референсы.

Значения (цвета, размеры, типографика, движение) по-прежнему живут в `design/pocket-puzzle-tokens.json`. Если материалы отсюда с ними расходятся, это обсуждаем и обновляем токены по правилам из CLAUDE.md (пересчёт контраста, запись в `changes`).
