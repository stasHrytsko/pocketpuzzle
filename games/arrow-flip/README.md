# Arrow Flip

Карточка игры. Источник: `stazzi/apps/casual/arrow-flip/` (SPEC.md, README, `src/levels`), прочитано 2026-11-03 по просьбе автора. Статус в stazzi — playable.

- **Статус:** MVP, ядро. **Уровней:** 25 (1–4 на поле 4×4, дальше 5×5).
- **Питч:** тапни блок — он уедет туда, куда смотрит стрелка. Каждый блок, которого он коснётся по дороге, поворачивается на 90° по часовой. Выведи все блоки за край поля.

## Правила
- Ввод только тапом по блоку. Блок едет по стрелке до соседнего блока или за край поля.
- Все блоки, которых он коснулся гранью (по всему пути), поворачиваются на 90° по часовой, один раз за ход. Сам едущий блок не поворачивается. Угол не считается.
- Ход допустим, если блок сдвинулся или ушёл за край. Тап по упёртому блоку — покачивание, ход не тратится.
- **Победа:** на поле не осталось блоков. Проверяется раньше лимита.
- **Поражение:** лимит ходов исчерпан при оставшихся блоках, либо тупик (ни у одного блока нет допустимого хода). Игра не предупреждает, что уровень уже непроходим; «Заново» всегда доступно.
- Спецклетки в поздних уровнях: камень, вертушка, якорь.
- Случайности и скрытой информации нет.

## Что на экране
Поле, счётчик ходов с лимитом, «?» (как играть), «Заново», выход к уровням. Задетые блоки коротко подсвечиваются.

## Уровни и сложность
Уровни сгенерированы (`tools/make-levels.ts`, фиксированное зерно) и руками не правятся; в `levels.ts` растёт число блоков: 4 → 11 → 20 к 18-му уровню. Солвер есть (`arrow-flip-solver.mjs`) и подтверждает, что на уровнях 3–5 жадная стратегия «запускай только те, что могут выйти» не проходит. **Для волны в письме сложность по уровням уже растёт по номеру** — отдельной оценки не нужно, годится номер уровня [проверить].

## Открытые вопросы
- Поражение по лимиту ходов и тупику: как это живёт в спокойном тоне (нужен «Заново» без наказания, не как провал).
- Игра сама не помечает непроходимое состояние: оставляем.
- Звук есть (Web Audio) — решить, как переносим в Unity.
