# Pocket Puzzle — заметки для Claude

Продуктовая концепция и дизайн сборника логических игр Stazzi с ежедневной почтой. Кода пока нет. Название Pocket Puzzle временное.

## Файлы

- `CONCEPT.md` — продуктовая концепция. Основная часть (§1–§12) — решения автора; приложения А–Г — исследования. При расхождении права основная часть.
- `design/pocket-puzzle-tokens.json` — токены и спецификация UI kit **v1.2**. Единый источник значений: цвета, типографика, отступы, компоненты, состояния, движение, звук, хаптика.
- `design/SCREENS.md` — полная карта экранов с ID (MVP / позже / соцслой). Новые экраны добавлять туда.
- `design/Pocket_Puzzle_Designer_Spec_v1.1.docx` — ТЗ дизайнеру v1.1. Устарело в частях, перечисленных в `changes` JSON; при расхождении действует JSON.
- Сами игры живут в монорепо `stasHrytsko/stazzi`, `apps/casual`. Движки не переписываются.

## Ключевые решения (31 октября 2026)

- Ядро — 3 игры в MVP: Arrow Flip, Perfect Fit, The Gap.
- Мета — почтальон: каждый день письмо с задачами → марки → оформление конверта → отправка → завтра новое. Вместо стрика — архив и счётчик отправленных писем.
- **Главная** — сегодняшнее письмо; входы: Моя почта (архив), Коллекция, Настройки. Вкладок Почта/Игры больше нет.
- **Коллекция** — только игры, которые хоть раз пришли в письме; пришла — открыта навсегда.
- **Социальный слой** (после MVP, по этапам): писать можно только через почтальона, одно письмо в день, ответ — только завтра, анонимно. **Письмо незнакомца запечатано головоломкой**, которую выбрал отправитель: прочитать можно, только решив её. Задержка доставки — окно для модерации. Свой текст — не раньше этапа 3 и только с фильтром, жалобой, блокировкой, возрастным порогом.
- Уведомления спрашивать только после первой отправки. На iOS PWA уведомления работают только после «добавить на экран Домой».
- MVP: только светлая тема, PWA, всё локально.

## Правила работы

- Отвечать автору по-русски, коротко, по-человечески.
- Не выдумывать цифры: прогресс, число уровней, проценты, отзывы. Нет данных — плейсхолдер в квадратных скобках или «нужно проверить». У The Gap сейчас 8 уровней.
- Не превращать примеры в правила: открытые продуктовые вопросы — в `CONCEPT.md` §11.
- Новые цвета и размеры брать из `design/pocket-puzzle-tokens.json`; любое изменение токенов — с пересчётом контраста и записью в `changes`.
- Отделять решения автора от выводов исследований; источники — ссылками.
- Не запирать ежедневное письмо, не терять историю, не заставлять угадывать, без рекламы внутри решения (`CONCEPT.md` §6).
