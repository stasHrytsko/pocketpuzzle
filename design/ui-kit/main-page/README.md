# Главная страница — «Комната»

Здесь всё про главную Pocket Puzzle: одну комнату, которую телефон показывает частями, а свайп двигает камеру между тремя зонами: Письма · Сегодня · Игры.

| Файл | Что это | Для кого |
|---|---|---|
| `ROOM-ART-BRIEF.md` | ТЗ иллюстратору v0.4: геометрия, слои и параллакс, стиль, палитра, предметы и состояния, что сдать, приёмка | Иллюстратор |
| `MAIN-PAGE-SPEC.md` | Поведение: камера, жест и остановка, параллакс, события и анимации предметов, доступность, системные жесты, проверки | Дизайнер, разработчик |
| `prototype/index.html` | **Кликабельная главная, самостоятельная страница**: скачать и открыть в браузере или через GitHub Pages. Собирается из `room.html` скриптом `prototype/build_standalone.py`, руками не править | Все |
| `prototype/room.html` | Интерактивный прототип комнаты (артефакт «Pocket Puzzle Room», https://claude.ai/artifact/KNL2BZwPJfe4EFJppo782r): свайп, параллакс, календарь, полка игр, попапы с размытием и ползунками размера. Арт — заглушки из простых форм | Все |
| `refs/room-panorama-v0.png` | Панорама от ИИ (2026-11-02): референс настроения и стиля частей. Для сборки не годится — пропорции 2,5:1 вместо 1,55:1; комнату собираем из частей (`../AI-PROMPTS.md` §12) | Все |
| `refs/room-mood-v1.png` | **Референс цвета комнаты** (решение автора, 2026-11-02: «главную делать в таких цветах») | Все |
| `refs/room-mood-v0.png` | Референс настроения (не финал). Что взять и что нет — в брифе | Все |

**Статус:** **база главной** (решение автора, 2026-11-02): ТЗ v0.7, поведение v0.6, прототип. Дальше — правками к базе. Арта и кода пока нет. Значения помечены **[решение]** (автор), **[предложение]** (стартовое, подобрать на телефоне), **[N]** (не определено).

Значения цветов, размеров и движения — `design/pocket-puzzle-tokens.json`. Экраны, в которые ведут предметы комнаты, — `design/SCREENS.md`.
