# Pocket Puzzle — заметки для Claude

Продуктовая концепция и дизайн сборника логических игр Stazzi с ежедневной почтой. Кода пока нет. Название Pocket Puzzle временное.

## Файлы

- `CONCEPT.md` — продуктовая концепция. Основная часть (§1–§12) — решения автора; приложения А–Г — исследования. При расхождении права основная часть.
- `design/pocket-puzzle-tokens.json` — токены и спецификация UI kit **v1.4**. Единый источник значений: цвета, типографика, отступы, компоненты, состояния, движение, звук, хаптика.
- `WORLD.md` — библия мира (черновик): ядро (решение автора), правила мира, связь механик с миром, линия почтальона, арки, тон, табу. Решения автора отмечены, остальное — предложения.
- `prototype/` — исходники кликабельного прототипа (артефакт на claude.ai) и самостоятельная страница `prototype/index.html`. **После любой правки прототипа сразу:** скопировать исходники в `prototype/`, выполнить `python3 prototype/build_standalone.py`, закоммитить (решение автора, 2026-11-01).
- `design/ui-kit/main-page/` — главная-«комната»: `ROOM-ART-BRIEF.md` (ТЗ иллюстратору v0.6), `MAIN-PAGE-SPEC.md` (камера, жест, параллакс, события, доступность), `refs/` (референс настроения). Правила: **комната показывает состояние, интерфейс — содержимое**; слева в арке календарь (закрашены дни, когда пришло письмо) и тумбочка с записками почтальона; в центре большой зелёный почтомат на маленьком пьедестале; справа три полки с играми; тап в любое место боковой зоны — **попап поверх размытой комнаты** (5 % по бокам, 10 % сверху и снизу, размытие 6); параллакс как в ТЗ; **вид за окном = время на телефоне, только день и ночь** (решения автора 2026-11-02); предмет едет с опорой; глубина только за окном; ничего не качается.
- `design/ui-kit/` — **новый UI kit** (решение автора, 2026-11-02): автор складывает сюда материалы. `@stazzi/puzzle-ui` не используем и не сверяем.
- `design/SCREENS.md` — полная карта экранов с ID (MVP / позже / соцслой). Новые экраны добавлять туда.
- `TECH-UNITY.md` — техническая основа: Unity, нативные iOS/Android, перенос игр на C#, аудит игр, токены → Unity.
- Исходные игры (TS) — монорепо `stasHrytsko/stazzi`, `apps/casual`. Движки **портируются на C#** (решение автора, 2026-11-02); генераторы уровней и солверы остаются там как офлайн-инструменты, Unity читает экспортированный JSON.

## Ключевые решения (31 октября 2026)

- Ядро — 3 игры в MVP: Arrow Flip, Perfect Fit, The Gap.
- Мета — почтальон: каждый день письмо с задачами → марки → оформление конверта → отправка → завтра новое. Вместо стрика — архив и счётчик отправленных писем.
- **Главная — три панели со свайпом (2026-11-01):** Письма ← **Сегодня** → Игры, открывается на «Сегодня». Подписи-кнопки «Письма · Сегодня · Игры» под контентом. **Одна главная кнопка внизу** на всех панелях, текст по состоянию (Новое письмо → Продолжить письмо → Оформить конверт → Прочитать записку → Продолжить игру). Конверт на «Сегодня» тоже нажимается. Письма: вкладки Отправленные / Записки (большой пазл сверху). Настройки — иконка в шапке. **Покупок нет** (отложено; игры не продаются).
- **Игры:** играть можно только в пришедшие по почте; пришла — открыта навсегда. **Темп (гипотеза автора, 2026-11-01, частоту тестировать):** первое письмо приносит сразу 3 игры, на 2-й день — 4-я, через неделю — 5-я, через 2 недели — 6-я. Не пришедшие видны с названием и картинкой, **без замка** — значок конверта «придёт по почте». Без групп «навыков мозга». **Задача из письма = следующий непройденный уровень этой игры и засчитывается в её прогресс** (решение автора, 2026-11-01). Страница игры: прогресс «N из M», сетка уровней 3 в ряд, по порядку, без замков (пройден — галочка, текущий — ▶, будущие — бледные), «Играть · уровень N».
- **Социальный слой** (после MVP, по этапам): писать можно только через почтальона, одно письмо в день, ответ — только завтра, анонимно. **Письмо незнакомца запечатано головоломкой**, которую выбрал отправитель: прочитать можно, только решив её. Задержка доставки — окно для модерации. Свой текст — не раньше этапа 3 и только с фильтром, жалобой, блокировкой, возрастным порогом.
- **Письмо (решение автора, 2026-11-01):** первое письмо открывается **вступлением** — введением в мир и игру. Главное в каждом письме — **записка почтальона игроку**: запечатана, открывается, когда решены все задачи. В UI это «записка», не «глава»; вкладка «Письма → Записки» — записки почтальона игроку. Решил всё → «Оформить конверт» (записка не стоит на пути) → после отправки «Прочитать записку». Оформление и отправка — один экран; марка = значок игры + время решения.
- **Вложение — глава истории мира** (кто почтальон, что за место, почему загадки). Запечатана, открывается наградой, когда решены все задачи письма. Главы — кусочки большого пазла, мета-игра «собери мир по крупицам». Главы идут по письмам, не по датам; коротко, можно пропустить, не нужны для игры. Нужна «библия мира» автора — главы не выдумывать, плейсхолдеры.
- **Тон истории — контраст:** оболочка спокойная и бумажная, история глубокая, мрачная, взрослая. Две части: основная линия (главы, одинаковые для всех, с MVP) и записки (разные у разных игроков, пересылаются другим игроком через почтальона, с v2). Картину мира целиком собирают вместе.
- **Мир (решение автора, 2026-11-01):** будущее; почтальон — сильный ИИ, оставшийся один; игроки — сознания людей, перенесённые в виртуальный мир; люди загнали себя гонкой за эффективностью и говорят только метриками и логикой; ИИ через бумагу и физические материалы, вопросами и саморефлексией, будит в них человечность. Вариант Б: тел нет, возврата нет — ИИ возвращает физическое внутрь человека. Подробно — `WORLD.md` §0.1.
- **Движок и платформа (решение автора, 2026-11-02):** всё на **Unity 6.3** (оболочка и игры, C#); MVP — нативные iOS и Android; комната — 2D-спрайты с параллаксом. Unity-проект живёт в этом репо, в папке `unity/`. Аналитика — **Firebase** (Analytics, Crashlytics, Remote Config + A/B). **Язык приложения в MVP — английский** (документация — на русском). Подробно — `TECH-UNITY.md`.
- **Порядок (решение автора, 2026-11-02):** сейчас только документация. Сначала согласуем общий визуал и дизайн приложения, потом добавляем игры по одной и приводим их дизайн и арт к нему. Код не пишем, пока визуал не согласован.
- Уведомления спрашивать только после первой отправки (системный запрос на iOS и Android).
- MVP: только светлая тема, всё локально, без сервера.

## Правила работы

- **Пушить в `main` всегда** — после каждой правки, вместе с веткой `ccr-f9cd9bfb-p3i6zy` (решение автора, 2026-11-01). Сначала `git fetch`, пушить только fast-forward; если `main` ушёл вперёд — сказать автору, не затирать.
- Отвечать автору по-русски, коротко, по-человечески.
- Не выдумывать цифры: прогресс, число уровней, проценты, отзывы. Нет данных — плейсхолдер в квадратных скобках или «нужно проверить». У The Gap сейчас 8 уровней.
- Не превращать примеры в правила: открытые продуктовые вопросы — в `CONCEPT.md` §11.
- Новые цвета и размеры брать из `design/pocket-puzzle-tokens.json`; любое изменение токенов — с пересчётом контраста и записью в `changes`.
- Отделять решения автора от выводов исследований; источники — ссылками.
- Не запирать ежедневное письмо, не терять историю, не заставлять угадывать, без рекламы внутри решения (`CONCEPT.md` §6).
