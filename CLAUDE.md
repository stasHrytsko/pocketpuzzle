# Pocket Puzzle — заметки для Claude

Продуктовая концепция и дизайн сборника логических игр Stazzi с ежедневной почтой. Кода пока нет. **Название — Postie, в сторе «Postie — daily puzzles»** (решение автора, 2026-11-03; заменяет временное Pocket Puzzle). До финала проверить: товарные знаки (USPTO, EUIPO, классы 9 и 41), домены, прямой поиск в App Store и Google Play. Известные совпадения: Postie — компания директ-мейл рекламы (другой рынок); «Postie Puzzle» — серия детского сериала «Number 1 Newton Avenue». Репо и папки пока называются pocketpuzzle — не переименовываем без отдельного решения.

- `design/ref/` — **новый дизайн (2026-11-03, прошлый удалён целиком)**: палитра Milk / Garden и UI kit «Milk · Apricot · Sage» (картинки-референсы). Токены и спецификацию собираем заново отсюда; пока только картинки. Из старого остались только `design/STRUCTURE.md` и `design/SCREENS.md` (структура, не визуал). Комната-главная, прототипы, greybox и сайт `web/` удалены — решение по ним откроем заново.

- `WORLD.md` — библия мира (черновик): ядро (решение автора), правила мира, связь механик с миром, линия почтальона, арки, тон, табу. Решения автора отмечены, остальное — предложения.
- `design/STRUCTURE.md` — **структура игры**: дерево экранов, три раздела (задание дня, все игры, история писем), главная, главная кнопка, цикл дня, навигация.
- `web/` — **сайт для показа и теста (Vercel, проект `postie`, https://postie-jade.vercel.app; корневой `vercel.json` отдаёт только `web/`)**: главная — коллекция из 12 игр (Cave In объединена с Parcels, решение автора 2026-11-03); у каждой играбельный уровень в новом дизайне, у Parcels два вида правил (2 уровня) (`web/js/<игра>.js`, движок чистый, в браузере без сборки); `design.html` — референсы дизайна, `app.html` — макет потока письма. Игры написаны заново (не код stazzi); проверка: `node tests/engines.test.js` (решения прогоняются через движки). Таймеров нет нигде (решение автора, 2026-11-03): у Tight Shelf таймер убран, остаётся цель «5 линий» и проигрыш, если фигура никуда не встаёт; очередь фигур по зерну. У Slide Out остаются счётчики целей, но они считают ходы, не время.
- `design/SCREENS.md` — полная карта экранов с ID (MVP / позже / соцслой). Новые экраны добавлять туда.
- `games/` — **папка под каждую игру**: ядро MVP `arrow-flip/`, `perfect-fit/`, `the-gap/`; дальше `slide-out/`, `tight-shelf/` и идеи `pary/`, `obval/`, `posylki/`, `na-vyrost/`, `kraski/`, `rusla/`, `chetyre-karty/`, `marble-selection/` (состав — решение автора, 2026-11-03; идеи перенесены из stazzi как `IDEA.md`): карточка игры, позже уровни, арт, макеты; общий набор файлов — `games/README.md` (решение автора, 2026-11-02).
- `TECH-UNITY.md` — техническая основа: Unity, нативные iOS/Android, перенос игр на C#, аудит игр, токены → Unity.
- Исходные игры (TS) — монорепо `stasHrytsko/stazzi`, `apps/casual`. Движки **портируются на C#** (решение автора, 2026-11-02); генераторы уровней и солверы остаются там как офлайн-инструменты, Unity читает экспортированный JSON.

## Ключевые решения (31 октября 2026)

- Ядро — 3 игры в MVP: Arrow Flip, Perfect Fit, The Gap.
- **В письме 3 задачи волной, как в NYT Pips: лёгкая → средняя → трудная** (решение автора, 2026-11-02): по одной из трёх разных игр, следующий непройденный уровень каждой, по возрастанию сложности.
- Мета — почтальон: каждый день письмо с задачами → марки → оформление конверта → отправка → завтра новое. Вместо стрика — архив и счётчик отправленных писем.
- **Главная — три панели со свайпом (2026-11-01):** Письма ← **Сегодня** → Игры, открывается на «Сегодня». Подписи-кнопки «Письма · Сегодня · Игры» под контентом. **Одна главная кнопка внизу** на всех панелях, текст по состоянию (Новое письмо → Продолжить письмо → Оформить конверт → Прочитать записку → Продолжить игру). Конверт на «Сегодня» тоже нажимается. Форма главной (три раздела вкладками или «комната») — открыто, решаем после структуры; прежнюю комнату удалили вместе со старым дизайном (2026-11-03). **Покупок нет** (отложено; игры не продаются).
- **Игры:** играть можно только в пришедшие по почте; пришла — открыта навсегда. **Темп (гипотеза автора, 2026-11-01, частоту тестировать):** первое письмо приносит сразу 3 игры, на 2-й день — 4-я, через неделю — 5-я, через 2 недели — 6-я. Не пришедшие видны с названием и картинкой, **без замка** — значок конверта «придёт по почте». Без групп «навыков мозга». **Задача из письма = следующий непройденный уровень этой игры и засчитывается в её прогресс** (решение автора, 2026-11-01). Страница игры: прогресс «N из M», сетка уровней 3 в ряд, по порядку, без замков (пройден — галочка, текущий — ▶, будущие — бледные), «Играть · уровень N». **Без выбора сложности** (решение автора, 2026-11-03). **Плашка игры в коллекции:** большая иконка внутри, под ней название, внизу полоса прогресса «N из M»; не пришедшая — бледная, значок конверта в углу вместо замка (решение автора, 2026-11-03, по референсу Almanac Training Mode).
- **Социальный слой** (после MVP, по этапам): писать можно только через почтальона, одно письмо в день, ответ — только завтра, анонимно. **Письмо незнакомца запечатано головоломкой**, которую выбрал отправитель: прочитать можно, только решив её. Задержка доставки — окно для модерации. Свой текст — не раньше этапа 3 и только с фильтром, жалобой, блокировкой, возрастным порогом.
- **Письмо (решение автора, 2026-11-01):** первое письмо открывается **вступлением** — введением в мир и игру. Главное в каждом письме — **записка почтальона игроку**: запечатана, открывается, когда решены все задачи. В UI это «записка», не «глава»; вкладка «Письма → Записки» — записки почтальона игроку. Решил всё → «Оформить конверт» (записка не стоит на пути) → после отправки «Прочитать записку». Оформление и отправка — один экран; **марка = только значок игры, без времени решения** (решение автора, 2026-11-03).
- **Одна записка на письмо** (решение автора, 2026-11-03): главы основной линии — часть записок, одинаковая для всех; остальные записки у каждого свои. Запечатана, открывается, когда решены все задачи. Кусочки большого пазла, мета-игра «собери мир по крупицам»; идут по письмам, не по датам; коротко, можно пропустить, не нужны для игры. Канон — `world/`; тексты пишет автор.
- **Тон истории — контраст:** оболочка спокойная и бумажная, история глубокая, мрачная, взрослая. Две части: основная линия (главы, одинаковые для всех, с MVP) и записки (разные у разных игроков, пересылаются другим игроком через почтальона, с v2). Картину мира целиком собирают вместе.
- **Мир (решение автора, 2026-11-01; уточнения 2026-11-03 — `WORLD.md` §0.1):** будущее; почтальон — сильный ИИ, оставшийся один; игроки — сознания людей, перенесённые в виртуальный мир; люди загнали себя гонкой за эффективностью и говорят только метриками и логикой; ИИ через бумагу и физические материалы, вопросами и саморефлексией, будит в них человечность. Вариант Б: тел нет, возврата нет — ИИ возвращает физическое внутрь человека. **Правда раскрывается слоями, очень медленно:** сначала кажется, что кто-то знает о тебе слишком много и даёт задания (не маньяк — 2026-11-02); потом — эксперимент; потом — далёкое будущее и ИИ, который пытается достучаться и помочь. **Пазл в пазле в пазле, мир без конца** (2026-11-02): головоломки → записки → внешний мир; финала нет, записки — окно, через которое узнаёшь всё больше (как живёт мир, что было в такой-то год, кто почтальон). Мир — один из слоёв, не основной. **Люди не пошли в радикальный гуманизм, а ушли ещё глубже в достигаторство** (соцсети, инфлюенсеры, «быть лучше ИИ») и потеряли душу ради достижения (2026-11-02). **Технофеодализм** (2026-11-02): правят компании; работаешь на компанию или ты в низшем классе; компании внедряют чипы в мозг. **Почтальон — фигура спасителя** (2026-11-02): хочет спасти и достучаться так, как люди могут услышать; **никогда не называется явно**, игроки откапывают сами. **Записки — как святое писание по подаче:** трактуются по-разному, без конкретики, как визг тормозов ночью — образ точный, событие несказанное. **Казуальные игры + вики-мир** (2026-11-02): как SCP / лор Dark Souls; разным игрокам — разные письма и записки; шифры в играх, которые никак не мешают казуальным игрокам. Подробно — `WORLD.md` §0.1.
- **Движок и платформа (решение автора, 2026-11-02):** всё на **Unity 6.3** (оболочка и игры, C#); MVP — нативные iOS и Android. Unity-проект живёт в этом репо, в папке `unity/`. Аналитика — **Firebase** (Analytics, Crashlytics, Remote Config + A/B). **Язык приложения в MVP — английский** (документация — на русском). Подробно — `TECH-UNITY.md`.
- **Порядок (решение автора, 2026-11-02):** сейчас только документация. Сначала согласуем общий визуал и дизайн приложения, потом добавляем игры по одной и приводим их дизайн и арт к нему. Код не пишем, пока визуал не согласован. **Арт и визуал на паузе (решение автора, 2026-11-02): сначала структура игры** (`design/STRUCTURE.md`), графикой пока не занимаемся.
- Уведомления спрашивать только после первой отправки (системный запрос на iOS и Android).
- MVP: только светлая тема, всё локально, без сервера.

## Правила работы

- **Пушить в `main` всегда** — после каждой правки, **только в `main`**; других веток не создавать и не пушить (решение автора, 2026-11-02: старые ветки удалены, `main` — дефолтная). Сначала `git fetch`, пушить только fast-forward; если `main` ушёл вперёд — сказать автору, не затирать.
- **Не смотреть в репо `stasHrytsko/stazzi` и не применять его правила** (CLAUDE.md, токены, `@stazzi/puzzle-ui`), пока автор не скажет (решение автора, 2026-11-02). Исключение — по прямой просьбе автора за конкретным материалом (2026-11-03: идеи и IDEA.md игр перенесены в `games/`). Pocket Puzzle — отдельный продукт со своими токенами.
- Отвечать автору по-русски, коротко, по-человечески.
- Не выдумывать цифры: прогресс, число уровней, проценты, отзывы. Нет данных — плейсхолдер в квадратных скобках или «нужно проверить». У The Gap сейчас 8 уровней.
- Не превращать примеры в правила: открытые продуктовые вопросы — в `CONCEPT.md` §11.
- Новые цвета и размеры — только из нового дизайна (`design/ref/`), после того как токены будут записаны; с пересчётом контраста.
- Отделять решения автора от выводов исследований; источники — ссылками.
- Не запирать ежедневное письмо, не терять историю, не заставлять угадывать, без рекламы внутри решения (`CONCEPT.md` §6).
